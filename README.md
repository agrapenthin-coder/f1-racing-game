# Formula Apex

A self-contained, Formula-style browser racing game. It uses an original red-and-white open-wheel race car and a perspective-rendered road—no external assets or libraries.

## Play

Open `index.html` locally, or enable GitHub Pages for this repository:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then save.

## Controls

- **W / Up Arrow** — accelerate
- **S / Down Arrow** — brake
- **A / Left Arrow** — steer left
- **D / Right Arrow** — steer right

Complete three laps to finish.
